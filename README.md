# MOTION OR3 — code, protocols and frozen records of Paper 1

This repository contains the code, the pre-registered protocols and the frozen records of the study
*A New Sensor Has No Identity: Transfer Cost and the Week That Narrows the Gap in a Per-Node
Congestion Classifier* (IEEE Transactions on Intelligent Transportation Systems, submitted). It also
contains the earlier pipeline of the MOTION project deliverable from which the study started.

The working language of the project was Italian. Protocols, frozen records, code comments and
folder names are in Italian; this README, the glossary (`GLOSSARY.en.md`), the experiment summaries
(`protocol/SUMMARIES.en.md`) and the translation of the register of corrections
(`register_of_corrections.en.md`) are in English. Where an English file and an Italian original
differ, **the Italian original is the record**: its fingerprint is the one cited in the paper. The
Italian `README.it.md` is the guide of the earlier deliverable campaign.

## What is where

| Path | Content |
|---|---|
| `protocol/E*.md` | pre-registered protocol of each experiment (signed, dated, with the commit at signature) |
| `CONGELAMENTO_*.md` | frozen record of each experiment, generated by the matching `genera_congelamento_*.py` |
| `genera_congelamento_*.py` | generators of the frozen records (one per experiment) |
| `protocol/e14b/`, `protocol/e15/`, `protocol/e16/` | frozen inputs and bundles of E14 stage B, E15 (including the timing logs under `tempi/`) and E16 |
| `evoluzione/componente/` | model, identity providers, adaptation |
| `evoluzione/esperimenti/` | experiment runners (`esegui_e*.py`), training (`addestramento.py`), insertion (`inserimento.py`) |
| `evoluzione/analisi/` | analyses and figure scripts (`--lingua en` produces the figures of the paper) |
| `analysis/` | `main.py` (regeneration of every number), `tabelle_paper1.py` (checks of the values printed in the manuscript), `tabelle_suppl.py` (supplementary tables), `impronte.py` (fingerprints) |
| `analysis/rigenerazione/CONFRONTO.md` | report of the last complete regeneration (committed) |
| `paper/SCHEDA_FATTI.md` | fact sheet for the internal review (bootstrap, partitions, adaptation mode, dates per episode), generated by `evoluzione/analisi/scheda_fatti.py` |
| `checks/` | preflight checks run before every launch |
| `results/evoluzione/` | per-cell predictions, aggregates, checkpoints, `*_risultati.json` and `congelamento_*.json` (**not under version control**, see below) |

Everything else at the root (scripts, `models/`, `baselines/`, `geo_sweep/`, `prereg/`, ...) belongs
to the earlier deliverable campaign described in `README.it.md`.

## Results and per-cell predictions

`results/` (about 22 GB on the authors' machines) holds the per-cell predictions, the aggregates,
the checkpoints and the JSON versions of the frozen records. The small files whose fingerprints are
cited by the protocols, the frozen records or the paper are in the repository at their original
paths under `results/evoluzione/`; the per-cell predictions, aggregates and checkpoints are archived
at Zenodo, <https://doi.org/10.5281/zenodo.23796058> (tag `paper1-freeze-20261030l`), to be unpacked under `results/evoluzione/`. The SHA-256 of the external data
files are recorded in `evoluzione/ADDENDUM_PEMS04.md` (PEMS04) and `protocol/E6.md` (PEMS08).

## Reproducing every number

From the repository root, with the environment of `pyproject.toml`:

```
poetry install
poetry run python analysis/main.py --elenco        # list of phases, nothing is run
poetry run python analysis/main.py                 # complete regeneration
poetry run python analysis/main.py --solo E4 E5    # selected experiments only
poetry run python analysis/main.py --senza-paper   # compare with the frozen records only
```

`main.py` re-runs, from the per-cell predictions and aggregates in `results/evoluzione/`, every phase
that does not train or evaluate models: selections on validation, comparisons with joint resampling,
curves, coverage analyses, and every generator of the frozen records (phases ARCH, E2, E3, E4, E3bis,
E5, E6, E7, E8, E14, E16, E15). Training, model evaluation on the cells, adaptation and the measured
timings are inputs: they are not re-run, and their fingerprints are recorded.

- **Sandbox.** Everything runs in `analysis/rigenerazione/<timestamp>/radice/`, on a copy-on-write
  clone of `results/evoluzione/`; the real results are fingerprinted before and after, and the run
  fails if anything changed.
- **Comparison.** Every regenerated number is compared with the frozen one within
  |Δ| ≤ 10⁻¹⁰ + 10⁻⁹ · |frozen|; Markdown records are compared line by line with dates and
  fingerprints masked; the values printed in the manuscript are checked by `analysis/tabelle_paper1.py`.
- **Report.** `analysis/rigenerazione/CONFRONTO.md` (committed after each complete run) states the
  outcome ("TUTTO COINCIDE" = everything coincides), the commit of the code, the identity of the
  manuscript (commit and SHA-256 of `main.tex` and `supplementary.tex`) and every difference.
- **Manuscript.** The manuscript is not in this repository. With `--paper <dir>` (default
  `../paper1`) the run also writes the English figures and the supplementary tables into
  `<dir>/figures/`; `--senza-paper` skips it.
- **Tags.** Verified states are tagged `paper1-freeze-<date><letter>` (from `paper1-freeze-20261010d`
  to `paper1-freeze-20261028j`); `CONFRONTO.md` at the tagged commit reports the complete run of that
  state, and any exception is noted in it.

## Protocol, records and corrections

Each experiment was pre-registered in `protocol/E<n>.md` before launch (arms, numerical criterion,
controls, invalidating conditions); deviations are declared with date and reason in the frozen
record. Every number of the paper comes from a frozen record generated by script. Corrections made
to the pipeline during the study are listed in `protocol/REGISTRO_CORREZIONI.md` (Italian, the
record) and translated in `register_of_corrections.en.md`; the dated corrections are also in the
protocols and records of the experiments they concern.

## Terms

The Italian terms used in file names, folders and code (`congelamento`, `impronta`, `cella`,
`braccio`, `statica`, `fascia`, ...) are translated in `GLOSSARY.en.md`.
